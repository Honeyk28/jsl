# JavaScript Laboratory – JSL

A collection of 12 JavaScript practicals developed to understand and implement core concepts of JavaScript, DOM manipulation, browser storage, asynchronous programming, timers, ES6 features, and jQuery.

## About the Repository

This repository contains 12 JavaScript laboratory practicals designed to build a strong foundation in client-side web development.

Each practical is implemented using HTML, CSS, and JavaScript. The programs focus on simple logic, practical implementation, readable code, and interactive browser-based output.

## Technologies Used

- **HTML5** – Structure of web pages and forms.
- **CSS3** – Styling and responsive layouts.
- **JavaScript (ES6)** – Programming logic, functions, events, and browser interactions.
- **jQuery 3.7.1** – DOM manipulation, event handling, and AJAX.
- **Web Storage API** – localStorage and sessionStorage.
- **JSONPlaceholder / DummyJSON APIs** – Sample data for AJAX operations.
- **Visual Studio Code** – Code editor.
- **Google Chrome** – Testing and execution.

## List of Practicals

### Practical 01 – JavaScript Introduction

**Aim:** To understand the basics of JavaScript and demonstrate inline and internal JavaScript.

**Concepts Covered:**
- Introduction to JavaScript.
- Inline and internal JavaScript.
- Variables and functions.
- Button click events.
- Browser alert and console methods.

**File:** `Practical-01.html`

### Practical 02 – Variables and Data Types

**Aim:** To understand JavaScript variables, data types, operators, and template literals through a billing calculator.

**Concepts Covered:**
- `var`, `let`, and `const`.
- JavaScript data types.
- Arithmetic operators.
- Array destructuring.
- Template literals.
- Basic billing calculations.

**File:** `Practical-02.html`

### Practical 03 – Conditional Statements and Loops

**Aim:** To implement conditional statements and looping concepts through a student grading system.

**Concepts Covered:**
- `if`, `else if`, and `else`.
- Comparison operators.
- Logical conditions.
- Loops.
- Grade calculation based on marks.

**File:** `Practical-03.html`

### Practical 04 – JavaScript Functions

**Aim:** To understand different types of JavaScript functions through a palindrome checker.

**Concepts Covered:**

- Function expressions.

- Closures.

**File:** `Practical-04.html`

### Practical 05 – JavaScript Arrays and Array Methods

**Aim:** To demonstrate JavaScript arrays and their built-in methods through a shopping cart application.

**Concepts Covered:**

- `push()` method.

**Aim:** To understand JavaScript string methods and operations through a string analyzer.

### Practical 09 – Browser Storage

## How to Run the Practicals

1. Clone the repository:

   ```bash
   git clone https://github.com/Honeykalastar/jsl.git
   ```

2. Navigate to the project directory:

   ```bash
   cd jsl
   ```

3. Open the project in Visual Studio Code:

   ```bash
   code .
   ```

4. Open the required practical HTML file.

5. Run the file using **Live Server** in VS Code.

6. View the output in Google Chrome or another modern browser.

**Note:** Practicals using external APIs or jQuery CDN require an active internet connection. Using Live Server is recommended, especially for asynchronous requests and ES6 modules.
